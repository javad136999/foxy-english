# فاکسی؛ انگلیسی با بازی (PWA)

## اجرا
1. **GitHub:** پوشه را در یک ریپوی جدید آپلود کنید.
2. **Vercel:** Add New Project، ریپو را انتخاب کنید، Framework = Other، Deploy.
3. **Supabase (اختیاری، همگام‌سازی پیشرفت):** پروژه بسازید، `supabase/schema.sql` را در SQL Editor اجرا کنید، سپس `SB_URL` و `SB_KEY` (anon key) را بالای اسکریپت `index.html` پر کنید.

## آماده‌سازی برای کافه‌بازار و مایکت
- خروجی APK: با Bubblewrap (TWA) یا Capacitor از آدرس Vercel. آیکن ۵۱۲ آماده است؛ اسکرین‌شات‌ها را خودتان بگیرید.
- آدرس `/privacy` را در فرم انتشار بدهید و ایمیل را در `privacy.html` بنویسید.
- ردهٔ سنی کودکان را انتخاب کنید و تبلیغ فقط از شبکه‌های مناسب کودک (مثل تپسل با فیلتر سن) بگذارید.
- در `buy()` پرداخت درون‌برنامه‌ای بازار/مایکت و در `showAd()` کد SDK تبلیغ را قرار دهید (فعلاً نمایشی‌اند).
- صدای تلفظ از موتور گفتار گوشی می‌آید. برای کیفیت یکسان، بعداً فایل صوتی ضبط‌شده اضافه کنید.

## ساختار محتوا
کلمه‌ها در آرایه `CL` ابتدای اسکریپت‌اند. دسته جدید = یک خط. دسته‌های هر سن در `AG`. دو دسته اول هر سن رایگان است (`FREE`).

## اشتراک مادام‌العمر کافه‌بازار

دو دسته اول رایگان هستند و دسته‌های بعدی تا زمان تأیید خرید قفل می‌مانند. قیمت محصول مادام‌العمر در طراحی محصول **۲۰۰٬۰۰۰ تومان** است و شناسه پیشنهادی محصول `foxy_lifetime` است.

پروژه فعلی یک PWA وب است و به‌تنهایی به SDK پرداخت کافه‌بازار دسترسی ندارد. برای خرید واقعی باید یک APK/Wrapper اندرویدی با همین package name ساخته و در پنل توسعه‌دهندگان بازار یک محصول دائمی با شناسه `foxy_lifetime` ایجاد شود. Wrapper باید پس از دریافت و تأیید رسید بازار، تابع JavaScript زیر را صدا بزند:

```js
window.foxyPurchaseComplete({
  productId: 'foxy_lifetime',
  purchaseToken: '<verified-token>'
});
```

اپ فقط در صورت دریافت `productId` درست و `purchaseToken` معتبر، همه دسته‌ها را فعال می‌کند. تابع `buy()` در نسخه وب به‌صورت عمدی خرید جعلی یا فعال‌سازی localStorage انجام نمی‌دهد.
